# LISENZO TOP UP

এই package একটি clean starter website:
- eFootball coin products
- Buy Now order form
- Admin demo dashboard
- Responsive design
- Default products: 100/200/500 coins

## গুরুত্বপূর্ণ
এই versionটি localStorage ভিত্তিক demo। Production website হিসেবে চালানোর আগে secure server-side authentication, database এবং payment/order backend লাগবে। কোনো secret key এই package-এ রাখা হয়নি.

Deployment:
1. index.html, admin.html, app.js, admin.js, style.css একই folder-এ রাখুন।
2. Cloudflare Pages বা GitHub Pages-এ publish করুন।
3. Production database/payment integration পরে যুক্ত করুন.
